# LexiQuiz Product Roadmap

Документ описує стратегічні етапи розвитку вебзастосунку **LexiQuiz (WordForge)** від стабільного MVP до розширеної платформи персоналізованого та соціального вивчення мов.

---

## v0.1 — Stable MVP

Мета версії: забезпечення надійності, стійкості монорепозиторію, повного покриття CI/CD та надання стабільного середовища для вивчення слів.

- [x] JWT Авторизація (Access Token + HttpOnly Refresh Token Cookie)
- [x] Ротація сесій та відкликання Refresh токенів (`UserSession`)
- [x] Управління наборами слів (CRUD, приватність Private/Public)
- [x] Розумний масовий імпорт слів із підтримкою складних слів із дефісами (`well-being`, `mother-in-law`)
- [x] Інтерактивні картки (Flashcards) з гарячими клавішами та жестами
- [x] Рушій квізів 4 типів (`multiple_choice`, `direct_typing`, `reverse_typing`, `true_false`)
- [x] Алгоритм інтервального повторення Spaced Repetition (SM-2)
- [x] Відстеження щоденної мети та серії днів (Streak) з урахуванням локального часового поясу
- [x] Контрольовані версіоновані міграції TypeORM
- [ ] **Зелений CI/CD Pipeline** з розділеними кроками перевірок
- [ ] **Production-ready Docker контейнеризація** (Backend, Frontend, PostgreSQL)
- [ ] **Frontend тестування** (Vitest, React Testing Library, Playwright E2E)
- [ ] Публічна демо-версія та централізований моніторинг помилок

---

## v0.2 — Learning Improvements

Мета версії: розширення інтерактивних методів навчання, зручність імпорту/експорту та покращення звукового супроводу.

- [ ] **Імпорт та експорт матеріалів**: Підтримка CSV, JSON та Anki deck `.apkg` імпорту/експорту.
- [ ] **Альтернативні переклади та синоніми**: Підтримка декількох допустимих варіантів перекладу для одного терміна.
- [ ] **Аудіовимова (Text-to-Speech)**: Інтеграція Web Speech API та серверної генерації вимови.
- [ ] **Алгоритм FSRS (Free Spaced Repetition Scheduler)**: Опціональне перемикання з SM-2 на FSRS для підвищення точності інтервалів.
- [ ] **AI-помічник**: Автоматична генерація контекстних прикладів уживань та контекстних підказок.

---

## v0.3 — Social & Community Features

Мета версії: перетворення застосунку на соціальну платформу для обміну матеріалами та групового навчання.

- [ ] **Каталог публічних наборів**: Пошук, фільтрація, категоризація та додавання чужих наборів до власної бібліотеки.
- [ ] **Спільне редагування та шеринг**: Можливість надавати права на редагування наборів колегам або учням.
- [ ] **Рейтинги та відзнаки**: Система досягнень (achievements), публічні лідерборди за кількість вивчених слів та активні серії днів.
- [ ] **Кабінет викладача (Teacher Groups)**: Створення груп учнів, призначення наборів та відстеження прогресу виконання завдань.

# ADR 001: Monorepo Architecture with npm Workspaces

- **Статус**: Прийнято (Accepted)
- **Дата**: 2026-08-06

## Контекст

Проєкт складався з двох основних частин: NestJS REST API бекенду та Next.js 14 App Router фронтенду. Необхідно було забезпечити спільну типізацію DTO, інтерфейсів та єдину систему лінтингу без дублювання коду у двох окремих репозиторіях.

## Рішення

Обрано структуру **Monorepo** на базі нативних **npm Workspaces**:

```text
LexiQuiz/
├── apps/
│   ├── backend/
│   └── frontend/
└── packages/
    └── shared-types/
```

## Наслідки

### Позитивні:
- Єдиний `package.json` у корені для збірки та тестування всього проєкту (`npm run build`, `npm run dev`).
- Прямий імпорт спільних типів через `@wordforge/shared-types`.
- Атомарні коміти, що охоплюють зміни у бекенді, фронтенді та типізації одночасно.

### Негативні / Ризики:
- Вимагає попередньої збірки `packages/shared-types` перед запуском перевірки типів чи збірки додатків у CI.

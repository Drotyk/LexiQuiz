# ADR 003: Spaced Repetition Algorithm (SM-2 Variant)

- **Статус**: Прийнято (Accepted)
- **Дата**: 2026-08-06

## Контекст

Дієве вивчення нових слів вимагає автоматичного розрахунку інтервалів повторення, щоб користувачі повторювали слова саме тоді, коли вони починають їх забувати.

## Рішення

Обрано модифікований алгоритм **SuperMemo 2 (SM-2)**:
- Кожне слово має свій стан у `LearningProgress` (`new`, `learning`, `reviewing`, `mastered`).
- Користувач оцінює картку за 4-бальною шкалою:
  - **1 (Again / Не знаю)**: скидання прогресу, інтервал 10 хвилин.
  - **2 (Hard / Важко)**: зменшення коефіцієнта легкості `easeFactor`, невелике збільшення інтервалу.
  - **3 (Good / Знаю)**: нормальне збільшення інтервалу.
  - **4 (Easy / Легко)**: збільшення `easeFactor` та суттєве зростання інтервалу.
- Встановлено максимально допустимий кап інтервалу в 365 днів (`maxInterval = 365`).

## Наслідки

### Позитивні:
- Алгоритм випробуваний часом, легкий у реалізації та обчислювально ефективний.
- Забезпечує персональний темп навчання для кожного користувача.

### Напрямки розвитку:
- У майбутніх версіях (v0.2) планується додати підтримку більш сучасного алгоритму FSRS (Free Spaced Repetition Scheduler).

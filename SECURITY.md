# Security Policy

Команда проєкту **LexiQuiz (WordForge)**серйозно ставиться до безпеки користувацьких даних, токенів авторизації та кукі-файлів.

---

## 🛡 Підтримувані версії

| Версія | Підтримка безпеки |
|---|---|
| 0.1.x (Stable MVP) | ✅ Так |
| < 0.1.0 | ❌ Ні |

---

## 🚨 Повідомлення про вразливості (Reporting a Vulnerability)

Будь ласка, **НЕ СТВОРЮЙТЕ** публічні GitHub Issues для повідомлення про безпекові вразливості.

Якщо ви виявили вразливість безпеки (наприклад, у механізмах JWT авторизації, ротації Refresh Cookie, SQL-ін'єкціях чи XSS):

1. Надішліть приватне повідомлення або електронний лист розробникам за адресою: **security@lexiquiz.app** (або через приватну систему виявлення вразливостей GitHub Security Advisories).
2. Надайте детальний опис вразливості та кроки для її відтворення (PoC).
3. Ми зобов'язуємося відповісти протягом **48 годин** та надати оцінку часу виправлення.

---

## 🔒 Принципи безпеки проєкту

- Усі `refreshToken` зберігаються у вигляді незворотних криптографічних хешів у PostgreSQL.
- Налаштовані `httpOnly`, `sameSite=lax` cookie для захисту від XSS атак.
- Впроваджено `Helmet` безпекові HTTP-заголовки та `@nestjs/throttler` для захисту від brute-force та DoS атак.
- Автоматичне сканування залежностей через Dependabot та аналіз коду CodeQL у CI/CD.
